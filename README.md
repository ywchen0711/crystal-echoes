# 水晶迴響 Crystal Echoes

HD-2D 風格的回合制 RPG，在瀏覽器裡就能玩：角色和怪物都是用小方塊堆出來的立體像素模型，放在有光影的立體場景裡，再加上移軸景深。

角色、世界和劇情全部原創。戰鬥與成長系統參考網路上對 2026 年 HD-2D 新作 FF 的系統介紹：時間軸、破防、全面擊潰 → 追加階段 → 共鳴、英雄迴響、召喚獸、祠堂試煉、委託板、坐騎與飛空艇。

**線上遊玩：** https://ywchen0711.github.io/crystal-echoes/

## 戰鬥系統

- **時間軸**：畫面上方顯示「本回合」與「下回合」的行動順序，速度越快越先動。
- **弱點與破防**：敵人頭上的盾牌數字是破防值。用弱點屬性或武器打中它，數字就會減少。減到 0 敵人就會「BREAK」：本回合和下回合都不能行動，受到的傷害 ×1.6。
- **全面擊潰 → 追加階段**：同一回合讓所有敵人都 BREAK，回合結束後全隊會多行動一次，傷害 ×1.3。
- **共鳴**：追加階段結束後，從隊員裝備的迴響中選一位，發動他的必殺技。
- **極限技**：受傷或攻擊會累積極限值，滿了就能使用角色專屬的極限技。
- **召喚獸**：召喚後參戰三回合，第三回合放出必殺技再離開。
- **接力**：蕾娜可以把自己的行動讓給隊友，對方會立刻行動。
- 右上角可以切換**自動戰鬥**和**兩倍速**。

## 裝備：1382 件，雙手各拿一樣

- **11 個裝備欄**：右手、左手、頭、身體、手、腰、腿、腳、背，加上兩個飾品。
- **雙手**：每隻手都可以拿武器或盾。兩手都拿武器就是二刀流，普通攻擊會用兩把武器各打一次，兩種武器的弱點都能打到。大劍、弓、法杖、豎琴是雙手武器。
- **16 種武器，各有自己的戰鬥規則**，不只是數值不同：

| 武器 | 規則 |
|---|---|
| 劍 | 攻擊後有機會招架敵人的物理攻擊並反擊 |
| 大劍 | 橫掃，波及第二個敵人；速度變慢 |
| 短劍 | 一次打兩下；對破防、睡眠、暈眩的敵人更痛 |
| 刀 | 每場戰鬥第一刀必定會心，會心傷害加倍 |
| 槍 | 刺穿到後面的敵人；打飛行敵人不減傷 |
| 斧 | 每次命中降低防禦，能擊碎重甲 |
| 戰鎚 | 無視重甲；不打弱點也有機會削破防值 |
| 弓 | 打飛行敵人更痛、必中、不會被反擊 |
| 火槍 | 無視防禦和重甲、必中，但不會會心 |
| 法杖 | 治療量提升，攻擊回復 MP |
| 魔杖 | 屬性魔法更強，打中弱點多削破防值 |
| 拳套 | 連續打同一個敵人，傷害越疊越高 |
| 長鞭 | 普通攻擊打全體，附加狀態機率加倍 |
| 迴旋鏢 | 普通攻擊打全體，克制飛行敵人 |
| 豎琴 | 普通攻擊改成演奏，替隊友加能力 |
| 魔導書 | 普通攻擊變成魔法，自動帶上敵人的弱點屬性 |
| 盾 | 有機率完全擋下物理攻擊；魔法盾還能擋魔法 |

- **敵人特性**：🪽 飛行（刀劍打不太到、弓和迴旋鏢很有效、土屬性無效）、🛡️ 重甲（要用戰鎚、火槍，或先用斧擊碎）、💨 敏捷（會閃開攻擊，弓、火槍、魔法必中）。
- **裝備效果**：附加屬性、命中時附加狀態、吸血、吸魔、會心、連擊、無視弱點破防、對某種怪物特攻、屬性抗性或吸收、防異常、自動加速／再生／反射、反擊、反傷、閃避、不屈、保護瀕死隊友、經驗、金幣、掉寶、遇敵率……。
- **戰技**：用某種武器戰鬥會提升熟練度，學會那種武器的 5 個戰技（共 85 個）。
- **鐵匠**：用強化石把裝備強化到 +5；用屬性寶石把屬性鑲到武器上，或讓防具抵抗那個屬性。
- 每個隊員擅長的武器不同，例如艾倫用劍、大劍、刀、斧、槍，蕾娜用斧、戰鎚、火槍、拳套、迴旋鏢、短劍。

## 怪物：182 種，每隻 4 種掉落

- 有經典 RPG 常見的怪物類型（名字和造型都是原創）：凝膠、布丁、角兔、貝西摩斯、奇美拉、曼提柯爾、食人魔、獨眼巨人、牛頭人、小惡魔、石像鬼、邪眼、幽靈、木乃伊、骷髏、活鎧甲、毒菇、仙人掌兵、臭氣花、甲蟲、毒蠍、蜘蛛、沙蟲、青蛙、烏龜、章魚、九頭蛇、炸彈火球、元素精靈、擬態寶箱、魔像、殺人機器、各色巨龍等。
- 同一種怪物有好幾個換色的強化版。
- 招牌能力：炸彈會自爆、仙人掌會射萬針（固定傷害）、臭氣花的惡臭氣息會附加一堆異常狀態、邪眼會混亂或石化、寶箱怪咬人很痛、蜘蛛會吐網。
- **秘銀凝膠／白金凝膠**：很少出現、一下就逃走、魔法無效、普通攻擊只能打 1。打出會心一擊就能一擊打倒，經驗值超多（刀的拔刀必定會心）。
- **4 種掉落**：常見（素材）、普通（消耗品）、稀有（寶石、種子或寶物）、極稀有（稀有裝備或果實）。頭目一定會掉一件稀有裝備。偷竊也是從這 4 種裡面偷，越稀有越難偷。
- **怪物圖鑑**（選單）：記錄遇過的怪物、能力、弱點、特性、出沒地點和 4 種掉落與機率。打倒 3 隻就會記住全部弱點。
- 新怪物會依照地形和等級出現在各地；通關後大地圖和迷宮會出現更強的怪物。

## 魔法：400 種

- 黑魔法、白魔法、時空魔法、咒術、秘術五個系統。
- 除了單體和全體，還有特殊的打法：連鎖彈跳、印記（下一次同屬性攻擊多削破防）、領域（3 回合屬性強化）、時限爆發、引爆異常狀態、雙屬性魔法（一次打兩種弱點）、讓敵人變成弱某屬性、直接削破防值、重力、停止、死亡宣告、反射……。
- **學法**：很多裝備帶有魔法（清單上有 ✦），裝備著打贏戰鬥會得到 AP，存滿就永久學會；城鎮的道具店也可以花錢學。

## 道具：500 種

回復、治療、復活、各屬性和各武器屬性的投擲道具（打中弱點也能破防）、狀態道具、強化藥、永久提升能力的種子和果實、40 道料理（之後 5 場戰鬥都有效果）、魔法卷軸、素材、屬性寶石、強化石、寶物、驅魔香和誘魔香等。

## 迴響水晶（英雄的力量）

- 每位隊員可以裝備一顆迴響，獲得能力加成和那位英雄的技能。
- 戰鬥會提升**羈絆**（1～5），羈絆越高，學會的技能越多。
- 羈絆也會讓隊員學會**被動能力**。學會後就算換了迴響也能繼續用，只要不超過 AP 上限。
- 用**迴響碎片**可以提升**星級**（★1～★3），能力加成會變強，魔法也會升級，例如火焰 → 烈焰 → 獄炎。
- 共有 8 位英雄：黎明騎士、星詠魔女、疾風盜賊、龍槍士、劍聖、吟遊詩人、聖女和機工師。
- 有兩位是劇情中取得。其他六位沉睡在各地的**光之祠堂**，要先看壁畫上的故事，再回答「如果你是我會怎麼做」的問題，答對才能得到。

## 世界與內容

- **4 章主線**：白帆港 → 低語森林 → 鐵砧城 → 風鳴礦坑 → 水都蒼瀾 → 沉沒神殿 → 浮空遺跡。每章都有頭目戰。
- **6 位隊員**：艾倫、希爾薇、米菈、塔洛、蕾娜和尼歐。上場 4 人，待命的隊員可以拿到一半經驗值。
- **委託板**：12 個支線任務，包括討伐、找失物、送信、捉迷藏（抓咪咕）、跳繩小遊戲和召喚獸試煉。
- **收集**：12 片石板碎片可以換獎品；寶箱和星鐵鍛造可以拿到星鐵武器。
- **競技場**：5 個等級，最高的「傳說級」要通關後才能挑戰。
- **通關後**：四處「封印之地」裡有超強頭目，打倒可以拿到最強武器。
- **坐騎**：機械鳥「啾比」跑得快、不會遇敵，還能走過淺灘；飛空艇「晨星號」可以飛到任何地方。
- **蝕夜六使**：灰燼的薩倫、嵐羽的緹雅、潮華的瑟琳、鐵面的瓦爾、拾憶的伊格，和首領「無聲者」歐勒斯。每一個人都是被某段歷史遺忘的人。
- **旅店夜話**：在旅店過夜時，夥伴們會聊起自己的過去（9 段）：艾倫想不起來的母親的臉、希爾薇記下的三個名字、塔洛的學費、蕾娜失蹤的父親、尼歐拿走的位置……有些夜話會開啟支線。
- **支線劇情**（選單→委託任務）：
  - 希爾薇的名冊：找到小隊三人的紀念石，把名字刻上神殿的牆
  - 塔洛的入學考：蒼瀾魔法學院的獎學金考試（考的是戰鬥知識）
  - 天匠的翅膀：飛上雷鳴峰，找到蕾娜父親的滑翔機「燕號」
  - 燈塔守的名字：薩倫的父親，和三十年前那個暴風雨夜
  - 潮華的歸來：瑟琳在鯨之淺灘等著尼歐
  - 拾憶者：十二片石板的真正意義，與歐勒斯最後的記憶
- **釣魚**：白帆港碼頭和蒼瀾運河，12 種魚（夜晚的港口有發光的魚），集滿有獎。咬餌時按確定，接著連按把黃色標記留在綠色區域裡。
- **難度**（設定→難度）：輕鬆／普通／困難。敵人的強度是用自動戰鬥模擬實測調整的：在劇情推進到那裡時的一般等級與商店裝備下，頭目戰大約 6–9 回合、最危險時隊伍剩 30–50% HP（`js/balance.js`）。
